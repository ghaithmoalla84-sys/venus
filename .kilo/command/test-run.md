شغّل اختبارات Venus وحلّل الإخفاقات وأصلحها ضمن نطاق الكود والاختبارات فقط.

1. شغّل الاختبارات من `D:\acc\tests`:
   ```
   cd D:\acc\tests; python -m pytest -q
   ```
   أو ملف/مجلد محدد إن ذُكر في $ARGUMENTS.
2. لا تلمس قواعد البيانات الحية (`venus.db`, `venus_notes.db`)؛ الاختبارات تستخدم fixtures مؤقتة.
3. عند الإخفاق: اقرأ التتبّع وحدّد الملف/السطر، وصلّح بأقل تغيير يحترم سلوك التطبيق.
4. أعد التشغيل حتى تمرّ الاختبارات؛ إن تعذّر الإصلاح بأمان اذكر السبب.
5. لا ترفع التغييرات بـ git؛ قل للمستخدم عند الحاجة.
6. لخّص: ما الذي فشل، وما المُصلَح، وعدد الاختبارات المارّة.
وسيط اختياري (مسار اختبار): $ARGUMENTS
